DeepSeek Harness Web UI 便携版
================================

【里面有什么】
  dsh-web.bat   一键启动器（核心）
  setup.bat     安装桌面快捷方式（带图标）——只用运行一次
  deepseek.ico  图标文件

【使用方法】
  第 1 步：双击 dsh-web.bat（或桌面「DSH Web UI」）
           - 如果电脑没有 Node.js，会问是否自动下载便携版 Node
             （按 Y 即可，自动下载安装，无需管理员权限）
           - 全部组件都装在包目录内（便携模式），
             不改系统设置、不写注册表，删文件夹即卸载
           - 已有 Node.js 则直接跳过这步

  第 2 步：把整个文件夹放到任意位置（比如 D:\ 或桌面），
           双击 setup.bat，桌面上会出现带图标的「DSH Web UI」
           ※ 如果之后移动了整个文件夹，需要重新双击一次 setup.bat

  第 3 步：双击「DSH Web UI」启动
           - 第一次运行需要下载组件，大约几分钟，请耐心等待
           - 下载慢或失败时，窗口会问你是否用国内镜像重试，按 R 即可
           - 启动后浏览器自动打开 http://127.0.0.1:3080

  第 4 步：首次使用请在界面右上角/设置里填入你自己的 API Key
           （DeepSeek 开放平台申请：https://platform.deepseek.com）

【常见问题】
  - 双击 bat 时 Windows 弹出蓝色"已保护你的电脑"提示：
    点"更多信息" → "仍要运行"即可（文件来自网络，属正常提示）
  - 火绒/360 等安全软件弹窗询问（npm 联网、安装软件）：
    点"允许"即可（本工具不写注册表、不改系统环境变量，
    弹窗概率极低；万一遇到，点允许或拒绝都不影响使用）
  - 微信收到的 zip 打不开/解压报错：让发送方用电脑版微信重新发一次
    （手机微信传文件偶尔会损坏）
  - 问"是否下载 Node.js"：电脑没装 Node 才会问，按 Y 自动装
  - 窗口会显示 [1/3] ~ [3/3] 三个大阶段标记当前进度：
    ① 检查 Node.js  ② 检查 dsh 组件  ③ 启动
    （下载/安装等细节以缩进小步骤显示，一切就绪时直接启动、零下载）
  - 某一步失败时会问是否重试（最多重试 3 次）
  - 3 次重试仍失败：窗口会给出具体的手动操作建议，照做即可
  - 中途关掉黑窗口也没关系：下次双击会自动识别进度，
    显示 [Resume] 提示并接着完成，不会从头再来
    （下载好的 Node 不会重下；装好的组件不会再下载）
  - 提示"文件夹不可写"：把整个文件夹移到 D:\ 或桌面等普通位置，
    不要放在 Program Files 这类受保护目录
  - 启动很慢：只有第一次慢（下载 + 系统扫描），之后都是几秒
  - 窗口显示端口被占用：说明已经有一个 dsh 在运行，
    此时直接打开浏览器访问 http://127.0.0.1:3080 即可
  - 关闭窗口 = 停止服务

【注意】
  - 这个包里不包含任何 API Key，请使用自己的 Key
  - 对话记录和配置保存在 用户目录\.dsh 下，重开都在
